
Open the program, and press run. In the main in the main2.c file you can choose which image to run the algorithm on by outcommenting every image except the one you want to process. The output images are located either in /samples/easy, /samples/medium, /samples/hard.

The Pattern is in a 7of8 pattern by default, but can also be changed to a 23of24 pattern by the variable patternSize from 1 to 2 Ln 19, and the neighborLimit from 7 to 23 Ln 18. 

If you want the results as in the marginborder change the variable bordermargin = 0 to bordermargin = 1 Ln 17.
